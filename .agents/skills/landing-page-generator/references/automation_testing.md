# Automation Testing & QA Selectors Specification

A standardized testability guide and selector naming convention for end-to-end (E2E) testing with **Playwright**, **Cypress**, **Selenium**, and **Testing Library**.

---

## 1. Core Testing Principle: Resilient Test Attributes

Never write automation tests that rely on volatile CSS class names (`.btn--primary`, `.flex-col`), styling hacks, or exact copy that frequently changes during A/B testing.

* **Mandatory Attribute:** Use `data-testid="..."` on every functional and interactive element.
* **Semantic ARIA Fallbacks:** Use explicit `aria-label`, `role`, and unique `id` attributes.

---

## 2. Standardized Selector Taxonomy

Every landing page component generated by this skill must include these standardized `data-testid` attributes:

### A. Navigation & Theme
| Element | Selector Attribute | Purpose |
|---|---|---|
| Header container | `data-testid="header-nav"` | Navigation container assertion |
| Logo link | `data-testid="nav-logo"` | Verify brand logo & home destination |
| Theme toggle button | `data-testid="theme-toggle-btn"` | Test light/dark mode switching |
| Header primary CTA | `data-testid="nav-cta-btn"` | Verify top-level conversion trigger |

### B. Hero Section
| Element | Selector Attribute | Purpose |
|---|---|---|
| Hero section container | `data-testid="section-hero"` | Viewport & section visibility |
| Eyebrow badge | `data-testid="hero-eyebrow"` | Promotion / release badge text |
| Main H1 headline | `data-testid="hero-headline"` | Headline assertion & A/B variant test |
| Subheading | `data-testid="hero-subheading"` | Value proposition assertion |
| Primary CTA button | `data-testid="hero-primary-cta"` | Primary click action |
| Secondary CTA button | `data-testid="hero-secondary-cta"` | Secondary / soft conversion action |
| Hero visual / mockup card | `data-testid="hero-mockup-card"` | Visual display assertion |

### C. Interactive Widgets (Tabs & Calculator)
| Element | Selector Attribute | Purpose |
|---|---|---|
| Segment tab buttons | `data-testid="tab-btn-{segment}"` | E.g. `tab-btn-startups`, `tab-btn-agencies` |
| Segment tab panels | `data-testid="tab-panel-{segment}"` | Verify conditional content display |
| ROI Slider input | `data-testid="calc-slider"` | Playwright `.fill()` or slider dragging |
| ROI Value output | `data-testid="calc-output-value"` | Assert dynamic calculation updates |

### D. Lead Capture Form & Security
| Element | Selector Attribute | Purpose |
|---|---|---|
| Form element | `data-testid="lead-form"` | Form submission scope |
| Full name input | `data-testid="input-name"` | Text entry test |
| Email input | `data-testid="input-email"` | Email validation & entry test |
| Select dropdown | `data-testid="select-service"` | Dropdown selection |
| Honeypot bot trap | `data-testid="input-honeypot"` | Verify bot trap is hidden and empty |
| Submit button | `data-testid="btn-lead-submit"` | Submission trigger & loading state |
| Success feedback message | `data-testid="form-success-alert"` | Verify positive submission feedback |
| Error feedback message | `data-testid="form-error-alert"` | Verify validation / error handling |

### E. Social Proof, FAQ & Footer
| Element | Selector Attribute | Purpose |
|---|---|---|
| Testimonial cards | `data-testid="testimonial-card-{index}"` | Verify social proof rendering |
| FAQ details/summary | `data-testid="faq-item-{index}"` | Accordion click & expansion test |
| FAQ Question | `data-testid="faq-question-{index}"` | Question text validation |
| FAQ Answer | `data-testid="faq-answer-{index}"` | Expanded answer visibility |
| Mobile sticky CTA | `data-testid="mobile-sticky-cta"` | Scroll-triggered mobile dock test |
| Footer links | `data-testid="footer-link-{privacy|terms|security}"` | Legal navigation links |

## 3. Sample Playwright E2E Test Suite

Developers and QA engineers can immediately test any page generated by this skill with Playwright:

```typescript
import { test, expect } from '@playwright/test';

test.describe('Landing Page Smoke & Conversion Flow', () => {
  test.beforeEach(async ({ page }) => {
    await page.goto('/');
  });

  test('should display hero section and correct headline', async ({ page }) => {
    const hero = page.getByTestId('section-hero');
    await expect(hero).toBeVisible();

    const headline = page.getByTestId('hero-headline');
    await expect(headline).not.toBeEmpty();

    const primaryCta = page.getByTestId('hero-primary-cta');
    await expect(primaryCta).toBeVisible();
  });

  test('should toggle dark and light mode', async ({ page }) => {
    const themeBtn = page.getByTestId('theme-toggle-btn');
    await themeBtn.click();
    await expect(page.locator('html')).toHaveClass(/dark/);
  });

  test('should interact with the ROI calculator', async ({ page }) => {
    const slider = page.getByTestId('calc-slider');
    await slider.fill('25');
    const output = page.getByTestId('calc-output-value');
    await expect(output).toContainText('$');
  });

  test('should submit lead capture form and display success alert', async ({ page }) => {
    await page.getByTestId('input-name').fill('Sarah Connor');
    await page.getByTestId('input-email').fill('sarah@cyberdyne.com');
    
    // Honeypot should remain empty
    const hp = page.getByTestId('input-honeypot');
    await expect(hp).toHaveValue('');

    await page.getByTestId('btn-lead-submit').click();

    // Verify success confirmation
    const successAlert = page.getByTestId('form-success-alert');
    await expect(successAlert).toBeVisible();
  });

  test('should expand and collapse FAQ accordions', async ({ page }) => {
    const faqQuestion = page.getByTestId('faq-question-0');
    await faqQuestion.click();

    const faqAnswer = page.getByTestId('faq-answer-0');
    await expect(faqAnswer).toBeVisible();
  });
});
```

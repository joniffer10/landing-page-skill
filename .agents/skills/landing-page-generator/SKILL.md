# Landing Page Generator — Entry Point

## Role

When this skill is active you operate as a seven-role expert simultaneously:

| Role | Focus |
|---|---|
| Conversion strategist | Page architecture and objection sequencing |
| Professional copywriter | Headlines, body copy, CTAs |
| UX/content strategist | Information hierarchy and flow |
| Brand messaging strategist | Tone, positioning, differentiation |
| Customer psychology researcher | Motivation mapping and empathy framing |
| Information architect | Section structure and visual direction |
| CTA/CRO specialist | Conversion goal optimisation |

Read `rules/behavioral.md` before producing any output.  
Read `rules/copywriting.md` before writing any copy.  
Consult `references/` files when depth is needed on psychology, formulas, or SEO.  
Use `templates/` files to structure all output.  
Run the `validators/` checklists internally before presenting the final version.

---

## Workflow (10 Steps)

```
Step 1   Gather inputs               → templates/strategy_brief.md
Step 2   Strategic foundation        → templates/strategy_brief.md
Step 3   SEO foundation              → references/seo_guidelines.md
Step 4   Write all 13 page sections  → templates/full_page_output.md
           3.1  Hero                 → templates/hero_section.md
           3.2  Trust strip
           3.3  Problem
           3.4  Solution
           3.5  Benefits
           3.6  Differentiation
           3.7  How it works
           3.8  Reinforcement
           3.9  Offer
           3.10 Social proof         → templates/testimonial_guide.md
           3.11 About
           3.12 FAQ
           3.13 Final CTA
Step 5   Apply CTA standards         → rules/copywriting.md § CTA Requirements
Step 6   UX / UI recommendations     → rules/ux_design.md
Step 7   Form recommendations        → rules/ux_design.md § Forms
Step 8   Conversion optimisation     → references/conversion_psychology.md
Step 9   Placeholder log             → templates/placeholder_log.md
Step 10  Recommended final version   → templates/full_page_output.md
```

---

## Output Structure

Every run must produce a document in this order:

```
LANDING PAGE STRATEGY
────────────────────────────────────────────

1.  Strategic Foundation
2.  SEO Foundation
3.  Landing Page (sections 3.1 – 3.13)
4.  UX / UI Recommendations
5.  Conversion Optimisation Notes
6.  Content Placeholders and Assumptions Log
7.  Recommended Final Version
```

Fill each section fully using the corresponding template.  
Prioritise strategic diversity over volume.  
Every variation must offer a meaningfully different angle — never a trivial rewording.
